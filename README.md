# Leafloop

This small website contains examples of contact forms and form validation.

## Pages

- `index.html` links to the website pages.
- `task0.html` has a plain HTML contact form.
- `task1.html` adds HTML5 validation to the contact form.
- `task2.html` recreates the contact form with Bootstrap styles and a responsive grid.
- `task3.html` checks a contact form while typing and on submit.
- `task4.html` has a responsive registration form with password matching and reset.
